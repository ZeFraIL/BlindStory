# תיאור מחלקה: SupabaseConfig

#### 1. מידע כללי
- **שם המחלקה:** `SupabaseConfig`
- **סוג:** מחלקה שירותית קבועה (Configuration Class)
- **תפקיד המחלקה באפליקציה:** מאחסנת את כתובת ה-URL ומפתח ה-Anon Key להתקשרות מול השרת והבסיס נתונים ב-Supabase.
- **אינטראקציה עם רכיבים אחרים:** ננקראת מתוך `AuthManager` ומקבילה להגדרות `BuildConfig.SUPABASE_URL`.

#### 2. משתנים (שדות המחלקה)

| שם | סוג | ייעוד |
|------|------|---------|
| `SUPABASE_URL` | `String` (קבוע) | כתובת השרת: `"https://jcnolrrpnnqpisbnoach.supabase.co"` |
| `SUPABASE_ANON_KEY` | `String` (קבוע) | מפתח הגישה הציבורי המאובטח של השרת |

#### 3. הסבר במילים פשוטות
**כמו הכתובת והמפתח של הבית:** המחלקה הזו מחזיקה את הכתובת של השרת באינטרנט ואת המפתח הציבורי שמאפשר לאפליקציה לדבר איתו בצורה בטוחה!
