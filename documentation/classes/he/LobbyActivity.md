# תיאור מחלקה: LobbyActivity

#### 1. מידע כללי
- **שם המחלקה:** `LobbyActivity`
- **סוג:** Activity
- **תפקיד המחלקה באפליקציה:** חדר ההמתנה (Lobby) לפני תחילת המשחק. מציג את קוד החדר, כפתורי העתקה ושיתוף קישור, כרטיס סיכום הגדרות המשחק, ורשימת שחקנים בזמן אמת עם תג "מארח".
- **אינטראקציה עם רכיבים אחרים:** מקבלת את נתוני החדר מ-`CreateRoomActivity` ועוברת ל-`GameActivity` בלחיצה על "התחל משחק".

#### 2. מנגנונים מרכזיים
- **חוק 3 השחקנים:** כפתור "התחל משחק" נעול במצב לא פעיל ומציג *"דרושים לפחות 3 שחקנים (1/3)"* עד שמצטרפים לפחות 3 שחקנים.
- **כפתור סימולציית בוטים (`btn_add_simulated_player`):** מאפשר למפתחים ולבודקים להוסיף שחקנים מדומים (כגון "מרינה", "מארק") כדי לבדוק את הפעלת כפתור התחלת המשחק.

#### 3. הסבר במילים פשוטות
**כמו חדר המתנה למסיבה:** כולם מתכנסים, רואים את הקוד של החדר, משתפים אותו עם חברים בוואטסאפ, וכשכולם מגיעים (לפחות 3 אנשים) — המארח לוחץ להתחיל את המשחק!
