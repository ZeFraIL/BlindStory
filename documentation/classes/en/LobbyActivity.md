# Class Description: LobbyActivity

#### 1. General Information
- **Class Name:** `LobbyActivity`
- **Type:** Activity
- **Role in Application:** Pre-game waiting lobby displaying room code, copy/share actions, player list, bot simulation, and enforcing the 3-player start minimum.
- **Interaction:** Receives parameters from `CreateRoomActivity` and launches `GameActivity`.

#### 2. Simplified Explanation
**Like a party waiting room:** Everyone gathers, shares room code, and once 3+ players join, host starts the game!
