# Class Description: LocaleHelper

#### 1. General Information
- **Class Name:** `LocaleHelper`
- **Type:** Utility Class
- **Role in Application:** Manages dynamic language changing (English, Russian, Hebrew, Lithuanian) via `AppCompatDelegate.setApplicationLocales`.
- **Interaction:** Called in `attachBaseContext()` across all Activities.

#### 2. Simplified Explanation
**Like a personal interpreter:** Ensures every screen is rendered in your chosen language!
