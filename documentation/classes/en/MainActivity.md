# Class Description: MainActivity

#### 1. General Information
- **Class Name:** `MainActivity`
- **Type:** Activity
- **Role in Application:** Main Dashboard. Features buttons to Create Room, Join by Code, view My Stories, Profile, and Public Rooms.
- **Interaction:** Navigates to `CreateRoomActivity`, `LobbyActivity`, `AuthActivity`.

#### 2. Simplified Explanation
**Like the main lobby of a game center:** Choose whether to host a new game table, join a friend's table, or view your profile!
