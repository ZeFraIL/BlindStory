# Class Description: CreateRoomActivity

#### 1. General Information
- **Class Name:** `CreateRoomActivity`
- **Type:** Activity
- **Role in Application:** Room constructor where the host configures room name, topic, starting phrase, rounds (1-3), turn time limit, privacy, and AI options.
- **Interaction:** Generates random 6-character room code and passes data to `LobbyActivity`.

#### 2. Simplified Explanation
**Like setting up game rules:** You decide topic, time, and rounds, then generate a code to invite friends!
