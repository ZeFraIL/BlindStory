# Описание класса: CreateRoomActivity

#### 1. Общая информация
- **Имя класса:** `CreateRoomActivity`
- **Тип:** Activity
- **Роль в приложении:** Конструктор комнаты. Ввод названия, темы, стартовой фразы, кругов (1-3), времени, приватности и параметров ИИ; генерация кода комнаты.

#### 2. Упрощенное объяснение
**Как составление правил игры:** Вы задаете тему, время и количество кругов, получаете секретный код и приглашаете друзей!
