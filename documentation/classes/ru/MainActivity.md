# Описание класса: MainActivity

#### 1. Общая информация
- **Имя класса:** `MainActivity`
- **Тип:** Activity
- **Роль в приложении:** Главный экран (Dashboard). Кнопки создания комнаты, ввода кода, истории рассказов, профиля и открытых комнат.
- **Взаимодействие:** Переход в `CreateRoomActivity`, `LobbyActivity`, `AuthActivity`.

#### 2. Упрощенное объяснение
**Как главное фойе игрового центра:** Выбирайте: открыть новый игровой стол, сесть за стол друга по коду или проверить свой профиль!
