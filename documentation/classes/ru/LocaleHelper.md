# Описание класса: LocaleHelper

#### 1. Общая информация
- **Имя класса:** `LocaleHelper`
- **Тип:** Служебный класс (Utility Class)
- **Роль в приложении:** Динамическая смена языка приложения через `AppCompatDelegate.setApplicationLocales`.

#### 2. Упрощенное объяснение
**Как личный переводчик:** Гарантирует, что каждый экран будет отображен на выбранном вами языке!
