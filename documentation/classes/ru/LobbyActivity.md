# Описание класса: LobbyActivity

#### 1. Общая информация
- **Имя класса:** `LobbyActivity`
- **Тип:** Activity
- **Роль в приложении:** Лобби ожидания перед игрой. Отображает код комнаты, кнопки копирования/шеринга, список игроков, кнопку добавления ботов и ограничение на запуск (мин. 3 игрока).

#### 2. Упрощенное объяснение
**Как комната ожидания перед вечеринкой:** Все собираются, делятся кодом, и когда набирается компания (не менее 3 человек) — ведущий заускает игру!
