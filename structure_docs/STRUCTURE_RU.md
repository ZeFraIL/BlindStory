# 🏛️ Архитектура и структура приложения «Слепой рассказ»

---

## 1. Общая картина (The Big Picture)

Приложение **«Слепой рассказ» (BlindStory)** — это коллективная словесная онлайн-игра. Код приложения логически разделен на три главных блока: **Визуальный слой (UI)** (экраны, которые видит игрок), **Игровая логика** (управление ходами, таймерами и языком), и **Слой данных** (сохранение сессии и бэкенд Supabase).

### 🏠 Наглядная аналогия: Театр
Чтобы понять, почему код разделен на отдельные части, а не написан в одном огромном файле, представим **театр**:
- **Сцена и декорации (`res/layout` + `Activities`):** То, что видит зритель — актеры, свет, виртуальные кнопки и экраны.
- **Режиссер и администратор (`AuthManager` + `LocaleHelper`):** Работают за кулисами — проверяют билеты авторизованных гостей и следят, чтобы все говорили на понятном языке.
- **Архив и касса (`Supabase`):** Хранит список всех зарегистрированных зрителей и все написанные пьесы-рассказы.

## 2. Обзор папок и файлов

В данном проекте Android код структурирован по следующей схеме:

```
BlindStory/
├── app/src/main/
│   ├── java/zeev/fraiman/blindstory/    <-- Исходный код Java (Логика)
│   │   ├── StartActivity.java           <-- Стартовый экран (Splash)
│   │   ├── LanguageActivity.java        <-- Выбор языка
│   │   ├── AuthActivity.java            <-- Авторизация и Регистрация
│   │   ├── MainActivity.java            <-- Главное меню
│   │   ├── CreateRoomActivity.java      <-- Конструктор комнаты
│   │   ├── LobbyActivity.java           <-- Лобби ожидания
│   │   ├── GameActivity.java            <-- Игровой экран хода
│   │   ├── FinalStoryActivity.java      <-- Финал и Анализ ИИ
│   │   ├── AuthManager.java             <-- Менеджер сессии
│   │   ├── LocaleHelper.java            <-- Менеджер языков
│   │   └── SupabaseConfig.java          <-- Конфигурация бэкенда
│   └── res/                             <-- Визуальные ресурсы
│       ├── layout/                      <-- XML-макеты экранов
│       └── values/                      <-- Тексты, цвета, темы
```

### Пояснение ключевых терминов:
- **Activity (Экран):** Компонент Android, отвечающий за конкретный экран приложения.
- **XML Layout (Макет):** Файл внешнего вида экрана (кнопки, текстовые поля, цвета).
- **SharedPreferences:** Быстрое локальное хранилище данных на смартфоне.
- **Supabase Backend:** Облачная база данных PostgreSQL, хранящая комнаты и рассказы.

## 3. Взаимодействие компонентов

Схема ниже иллюстрирует поток управления и передачу данных между экранами:

```
[StartActivity] (Таймер 4 секунды)
      │
      ▼
[LanguageActivity] (Выбор языка + сохранение в LocaleHelper)
      │
      ▼
[AuthActivity] (Вход/Регистрация + сохранение в AuthManager)
      │
      ▼
[MainActivity] (Главное меню) ───(Клик «Создать комнату»)───> [CreateRoomActivity]
      │                                                           │
      │                                                  (Генерация кода)
      ▼                                                           ▼
[LobbyActivity] <─────────────────────────────────────────────────┘
      │
(Минимум 3 игрока -> Клик «Начать игру»)
      ▼
[GameActivity] (Ввод фраз -> Финальный круг)
      │
      ▼
[FinalStoryActivity] (Чтение рассказа + Анализ ИИ)
```

## 4. Конкретный пример: Создание комнаты и запуск игры

Проследим путь выполнения программы при создании комнаты:

1. **Шаг 1 — Главное меню (`MainActivity.java`):**
   Пользователь нажимает кнопку `btn_create_room`:
   ```java
   btnCreateRoom.setOnClickListener(v -> {
       Intent intent = new Intent(MainActivity.this, CreateRoomActivity.class);
       startActivity(intent);
   });
   ```

2. **Шаг 2 — Конструктор комнаты (`CreateRoomActivity.java`):**
   Игрок заносит параметры и нажимает «Создать комнату». Выполняется метод `submitCreateRoom()`:
   ```java
   String roomCode = generateRandomRoomCode(); // например, "KOT123"
   Intent intent = new Intent(CreateRoomActivity.this, LobbyActivity.class);
   intent.putExtra(EXTRA_ROOM_NAME, name);
   intent.putExtra(EXTRA_ROOM_CODE, roomCode);
   startActivity(intent);
   ```

3. **Шаг 3 — Лобби ожидания (`LobbyActivity.java`):**
   Лобби отображает код `KOT123` и блокирует запуск до сбора 3 участников. Как только набирается группа, ведущий запускает `startGame()`:
   ```java
   Intent intent = new Intent(LobbyActivity.this, GameActivity.class);
   startActivity(intent);
   ```

4. **Шаг 4 — Игровой экран (`GameActivity.java`):**
   Открывается экран хода: видно только одну предыдущую фразу, игрок отправляет свой вариант!

## 📖 Краткий словарь терминов

1. **Activity:** Экран приложения в Android.
2. **Intent:** Запрос к системе Android на переход между экранами.
3. **Locale:** Настройки языка и региона пользователя.
4. **SharedPreferences:** Локальное хранилище данных на устройстве.
5. **Backend (Бэкенд):** Сервер в интернете, управляющий данными базы.
6. **CountDownTimer:** Класс Android для неблокирующего обратного отсчета времени.
